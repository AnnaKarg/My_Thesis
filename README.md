# AI Python Tutor

Πτυχιακή εργασία: **Σχεδίαση και Υλοποίηση Αυτόνομου Πράκτορα (Agentic AI) για Εξατομικευμένη Υποστήριξη και Αξιολόγηση Φοιτητών στον Προγραμματισμό**.

Το σύστημα διδάσκει Python σε αρχάριους μέσα από έναν προσωπικό **Mentor**, ο οποίος συνεργάζεται στο παρασκήνιο με δύο ακόμα πράκτορες — έναν **Debugger** και έναν **Assessor** — για να εντοπίζει λάθη, να αξιολογεί ολιστικά την πρόοδο του μαθητή και να προσαρμόζει τη δυσκολία και το ύφος της διδασκαλίας σε πραγματικό χρόνο.

## Γιατί Agentic

Ο πυρήνας της εργασίας δεν είναι ένα chatbot με ένα μεγάλο prompt, αλλά ένα **multi-agent pipeline** όπου κάθε πράκτορας έχει συγκεκριμένο ρόλο και παίρνει τη δική του απόφαση:

```
Κώδικας μαθητή
      │
      ▼
  ┌─────────────┐   δομικά στοιχεία (AST)     ┌────────────┐   αξιολόγηση        ┌──────────┐
  │  Debugger   │ ───────────────────────────▶│  Assessor  │ ──────────────────▶│  Mentor  │ ──▶ Μαθητής
  └─────────────┘   + κρίση LLM               └────────────┘   is_correct        └──────────┘
                                                advance/repeat/support           παιδαγωγικό hint
```

- **Debugger** — αναλύει τον κώδικα με `ast` (δομή, μεταβλητές, τύποι) και δίνει τα ευρήματα ως *δομημένη γνώση* σε ένα LLM, το οποίο αποφασίζει αν υπάρχει πρόβλημα και σε ποια κατηγορία ανήκει.
- **Assessor** — παίρνει την αναφορά του Debugger μαζί με ιστορικό (προσπάθειες, hints, χρόνος) και αποφασίζει ολιστικά: `advance` / `repeat` / `support`, και πόσο καλά έχει κατανοήσει ο μαθητής την έννοια.
- **Mentor** — παίρνει **μόνο** την τελική κρίση του Assessor (όχι τα ενδιάμεσα, ώστε να μην υπάρχουν δύο αντικρουόμενες πηγές αλήθειας) και τη μεταφράζει σε φυσική, παιδαγωγική γλώσσα — δίνει κατεύθυνση, όχι έτοιμη λύση.

Η θεμελιώδης αρχή: **δεδομένα από deterministic ανάλυση (AST, κριτήρια) τροφοδοτούν την κρίση του LLM**, αντί το LLM να αποφασίζει στα τυφλά — αυτό μειώνει το hallucination χωρίς να θυσιάζει την ευελιξία μιας πραγματικής συνομιλίας.

## Λειτουργίες

- **Εξατομικευμένο onboarding** — ο Mentor ρωτά την εμπειρία του μαθητή και προσαρμόζει θεωρία/ασκήσεις ανάλογα (beginner/expert).
- **5 κεφάλαια Python**: Μεταβλητές & Τύποι Δεδομένων, Δομές Ελέγχου, Λίστες, Επαναλήψεις, Συναρτήσεις — θεωρία, δυναμικά παραγόμενες ασκήσεις και targeted hints ανά κεφάλαιο.
- **Adaptive difficulty** — δυσκολία ασκήσεων προσαρμόζεται στην επίδοση, με δοκιμαστικό upgrade/downgrade όταν ο μαθητής τα πηγαίνει πολύ καλά ή δυσκολεύεται.
- **Αξιολόγηση Κώδικα (ελεύθερος έλεγχος)** — ο μαθητής μπορεί να δώσει δικό του κώδικα με μια σύντομη περιγραφή πρόθεσης και να πάρει άμεση ανάλυση από τον Debugger, χωρίς να «μετράει» ως βαθμολογούμενη άσκηση.
- **Open Learner Model** — προβολή προόδου ανά κεφάλαιο (mastery %, σημεία δυσκολίας) ώστε ο μαθητής να βλέπει πού στέκεται.
- **Ιστορικό συνομιλιών** — προηγούμενες συνεδρίες αποθηκεύονται και είναι προσβάσιμες από πλαϊνό sidebar.

## Τεχνολογίες

| Επίπεδο | Τεχνολογία |
|---|---|
| Backend | FastAPI, Python 3.13 |
| Agents / Orchestration | LangGraph, LangChain |
| LLM | Groq — `meta-llama/llama-4-scout-17b-16e-instruct` |
| Βάση δεδομένων | SQLite (τοπικά, async μέσω aiosqlite) / PostgreSQL (production) |
| Frontend | React 19, Vite, Monaco Editor |
| Observability | LangSmith |
| Deployment | Vercel (frontend) + Render (backend) + Neon (PostgreSQL) |

## Δομή Project

```
agents/          Mentor, Debugger, Assessor — η λογική κάθε πράκτορα
core/            LangGraph state machine (app.py) και σχήμα state (state.py)
api/             FastAPI endpoints (auth, chat, ιστορικό, ελεύθερος έλεγχος)
database/        SQLAlchemy models & session
content/         Ύλη μαθημάτων (lessons.json)
frontend/        React εφαρμογή
test_system.py   Automated tests (unit + pipeline integration)
```
